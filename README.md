# نظام صرح الإتقان المتكامل

تطبيق PWA متقدم لإدارة الحضور والانصراف والرواتب مع دعم الإشعارات والخرائط الجغرافية.

## ✨ الميزات

- 🏢 **إدارة شاملة**: لوحة تحكم للمدراء والموظفين
- 📱 **PWA متجاوب**: يعمل كتطبيق أصلي على الهواتف
- 🔔 **إشعارات فورية**: push notifications تعمل في الخلفية
- 🔐 **دخول مستمر**: لا يحتاج تسجيل دخول متكرر
- 🗺️ **خرائط جغرافية**: تتبع المواقع والمناطق الجغرافية
- 🌐 **دعم اللغة العربية**: واجهة RTL كاملة
- 📊 **تحليلات متقدمة**: تقارير وإحصائيات مفصلة

## 🚀 النشر

### المتطلبات
- Node.js 18+
- npm أو yarn

### التثبيت المحلي
```bash
npm install
npm run dev
```

### البناء للإنتاج
```bash
npm run build
```

### النشر على Vercel
التطبيق مُعد للنشر التلقائي على Vercel عبر GitHub Actions.

#### إعداد Vercel:
1. اربط المستودع بـ Vercel
2. أضف المتغيرات التالية في إعدادات المشروع:
   - `VERCEL_TOKEN`: رمز الوصول الخاص بك
   - `VERCEL_ORG_ID`: معرف المنظمة
   - `VERCEL_PROJECT_ID`: معرف المشروع

### النشر اليدوي
```bash
npm run build
# انسخ محتويات مجلد dist إلى خادم الويب
```

## 📱 كيفية الاستخدام

1. **التثبيت**: افتح التطبيق في المتصفح واضغط "تثبيت التطبيق"
2. **الدخول**: اختر نوع المستخدم (مدير/موظف)
3. **الاستخدام**: ابدأ في إدارة الحضور والرواتب
